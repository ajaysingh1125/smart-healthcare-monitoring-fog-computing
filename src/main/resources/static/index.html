Decentralized Fog Architecture & Data Pipeline
1. IoT Sensors

Wearables & bedside telemetry monitor HR, Temp, SpO2, and BP every 3 seconds.

2. Fog Node Edge

Local sub-10ms evaluation, bounded ring-buffer caching, abnormality detection.

3. Edge Filtering

70-80% routine normal telemetry filtered locally, drastically reducing cloud bandwidth.

4. Cloud / MongoDB

Immediate zero-latency cloud forwarding for CRITICAL readings and emergency alerts.
